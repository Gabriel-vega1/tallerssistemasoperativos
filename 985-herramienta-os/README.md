# Explorador del módulo `os`

Herramienta interactiva de consola para explorar funciones comunes del módulo
estándar `os`: directorio actual, listado, metadatos, creación de carpetas,
variables de entorno, información del sistema y espacio disponible.

Ejecuta `python herramienta_os.py` con Python 3.10+. Las operaciones que
escriben solo crean una carpeta con el nombre indicado dentro del directorio
actual; no elimina ni modifica archivos existentes.
