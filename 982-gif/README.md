# GIF: cómo viaja un paquete por la red

El archivo `paquete-red.gif` es una animación didáctica breve. Presenta cuatro
etapas: la aplicación crea datos, TCP los segmenta, IP los dirige y el destino
reconstruye el mensaje. Es un modelo simplificado: redes reales pueden usar
otros protocolos y varios saltos.
