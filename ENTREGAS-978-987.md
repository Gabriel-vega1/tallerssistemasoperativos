# Portafolio de tareas de Linux y programación

Repositorio organizado para las tareas 978–987. Cada carpeta contiene el
material de entrega y sus instrucciones. Proyecto educativo; usa los retos de
seguridad solo dentro del contenedor incluido.

## Requisitos generales

- Python 3.10 o posterior para tareas 985 y 987.
- Bash 4 o posterior para tareas 980, 981 y 986 (Linux, macOS o WSL).
- Docker con Compose para ejecutar el reto 987 de forma aislada.

Consulta el README de cada carpeta para instrucciones específicas. La tarea
986 reproduce los 18 scripts del texto que compartiste. Las tareas 978 y 987
se prepararon con un enunciado razonable porque no se compartió su guía exacta.

## Pendiente antes de considerar todo entregado

- **984:** falta compilar y arrancar LFS en un equipo Linux siguiendo la edición
  exacta de la guía oficial; aquí está solo la preparación y la bitácora.
- **979:** falta copiar el SVG al repositorio real de diapositivas; no se indicó
  cuál es ese repositorio.
- **978 / 987:** compara las propuestas con los enunciados originales por si
  piden ejercicios o un tipo de jail diferente.
- **GitHub:** el repositorio local está inicializado en la rama `main`, pero no
  tiene remoto ni se ha publicado. Añade la URL del repositorio y autentícate
  con GitHub para poder subirlo.

La fecha indicada para varias tareas ya pasó; confirma con tu docente si acepta
entrega tardía. La investigación de X11 se preparó el 26 de noviembre de 2026.
