# Ejercicios Easy / Intermediate / Difficult

Cada nivel tiene un enunciado y una solución Python. Ejecuta los programas con
`python easy.py`, `python intermediate.py` o `python difficult.py`.

## Easy — conteo de vocales

Recibe una frase y cuenta cuántas vocales contiene, sin distinguir mayúsculas.
La solución recorre el texto y suma cuando el carácter pertenece a `aeiou`.

## Intermediate — segundo valor distinto

Dada una lista de enteros, encuentra el segundo valor más grande distinto.
Si no existe, informa que la lista no tiene dos valores distintos.

## Difficult — par de suma objetivo

Dada una lista y un objetivo, devuelve índices de dos elementos distintos que
suman el objetivo en tiempo lineal promedio. Si no existe pareja, lo indica.
